Minifantasy - Portrait Generator includes:


+ An app folder
- HTML portrait generator app (opens in your browser)

+ A Graphical assets folder
- Aseprite files (original source .aseprite files used to create this asset pack)
- Single images (all portrait components as separate .png files)
- Sprite sheets (portrait components organized by category in .png files)


*** THE APP ***

TOP-CENTER ELEMENTS (general settings for your portrait):

- Scale slider: Determines the portrait preview size and the size of the downloads (except for the sprite sheets).
- Checkboxes for Blinking and Talking: Enable the corresponding animation in the portrait preview.
- Animation speed slider: Sets the duration of each animated frame (in milliseconds).
- Flip X-Axis: Flips the portrait preview so it faces left.
- Fantasy race selector: Changes the portrait preview to the selected fantasy race.
- Body height slider: Sets the character's height in the portrait.
- Dice icon: Randomizes a portrait.
- Lock base checkbox: Locks the currently selected fantasy race. When checked, clicking the Dice icon only generates a random portrait of the locked fantasy race.
- Keep hair color consistent checkbox: Ensures all hair-related components (hair, eyebrows, beard, and mustache) display in the same color.


MID-CENTER ELEMENTS (your creation ^^):

- Portrait preview: Shows a preview of the portrait you have created.


BOTTOM-CENTER ELEMENTS (save and download options):

- Disk icon: Saves a portrait in the app for later use. Stored at the bottom of the window.
- Picture icon: Downloads a .png of your current portrait preview.
- Picture + play icon: Downloads a .gif of your current portrait preview.
- Pictures album icon: Downloads your current portrait preview frames as a sprite sheet (only blinking, only talking, and blinking + talking sprite sheets).
- Multiple pictures icon: Downloads your current portrait preview as separate layers.


LEFT AND RIGHT SIDE ELEMENTS (portrait component layers):

- Name of the component + angle brackets: Cycle through the available options for that component.
- Eye icon: Makes the component hidden or visible.
- Up/down & left/right arrows: Offsets the component in those directions (1px per click).
- Colored circle: Opens the color picker (when available for that component).
- Dice icon: Randomizes that specific component.


SAVE SYSTEM

- As explained above, you can save your creations in the app (by pressing the disk icon).
- Saves (with small previews) are stored at the bottom of the app window.
- Page icon: Loads the selected portrait.
- Trashcan icon: Deletes the saved portrait.
- Share icon: Gives you a code that can be copied and pasted. Other app users can paste the code in the text field above the saved portraits to import portraits created by others.
